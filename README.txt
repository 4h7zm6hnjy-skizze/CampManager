CampManager v20 – komplette Version

Hauptdatei:
- index.html

Optional:
- supabase.sql für den Familien-/Mehrgeräte-Sync mit Supabase

Enthaltene Funktionen der v20:
- mehrere Stellplätze verwalten
- Profilbild je Stellplatz
- Kostenübersicht
- Jahresmiete mit Grundbetrag und inklusiven Übernachtungen
- Preise für Erwachsene und Kinder nach den inklusiven Übernachtungen
- Anzahl Autos + Jahrespreis pro Auto
- Anzahl Anhänger + Jahrespreis pro Anhänger
- automatische Berechnung der Jahresmiete
- Jahresabschluss mit PDF-Druckansicht
- Verträge monatlich oder jährlich
- Gasprüfung
- Petroleum-Verwaltung
- Strom-Jahreswerte inkl. Zählermiete
- Übernachtungszähler
- Rasen- und Heckenschnitt
- Dokumentenscanner / Dokumentenablage
- Gesprächstagebuch
- optionaler Supabase-Cloud-Sync
- Backup Import/Export

WICHTIG FÜR GITHUB:
Die Datei muss exakt index.html heißen. Eine Datei wie "index 2.html" oder "index 3.html" wird von GitHub Pages nicht als Startseite verwendet.

Wenn dein bestehendes GitHub-Projekt bereits logo.jpg enthält, bleibt dein bisheriges Logo erhalten. Die v20 nutzt weiterhin diese Datei.
