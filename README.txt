CampManager v22 – komplette Version

Neu in v22:
- Monatsbackup als einzelne Sicherungsdatei
- automatische Backup-Frage in den letzten Tagen jedes Monats
- Backup kann über iPhone/iPad direkt in der Dateien-App gespeichert werden
- vollständige Wiederherstellung aller CampManager-Daten an ihren ursprünglichen Stellen
- verfügbare gescannte Dokumentdateien werden in das Backup eingebettet und beim Import wieder in IndexedDB hergestellt
- ältere JSON-Backups bleiben importierbar

Wichtig:
Die App kann aus Sicherheitsgründen nicht selbständig ohne Benutzerauswahl in einen beliebigen iOS-Dateien-Ordner schreiben. Beim Backup wird deshalb das Teilen-/Speichern-Menü bzw. der Browser-Download geöffnet. Dort kann „In Dateien sichern“ gewählt werden.

Installation:
Alle Dateien in das Hauptverzeichnis des GitHub-Pages-Projekts hochladen. Die vorhandene index.html ersetzen.
